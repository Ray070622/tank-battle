# 🎮 坦克大战 Tank Battle

一个用纯 **HTML / CSS / JavaScript (Canvas)** 编写的经典坦克大战游戏，单文件即开即玩，无任何依赖。

## ✨ 特性

- 🗺️ **3 个手工设计的关卡**，通关后进入无尽模式，敌人逐级变强
- 🧱 **多种地形**：砖墙(可摧毁)、钢墙、水域(不可通行)、树林(可隐蔽)
- 🐣 **4 种敌人坦克**：普通型、快速型、火力型、装甲型(需 4 发)
- ⭐ **强化道具**：星标(增加子弹数)、火力(击穿钢墙)、生命(+1 条命)
- 🦅 **基地守护**：守住底部鹰旗，被毁即游戏结束
- 🎵 **Web Audio 音效**，按 `M` 可静音
- 🏆 **最高分本地保存** (localStorage)

## 🎮 操作方式

| 按键 | 功能 |
| --- | --- |
| 方向键 / `W` `A` `S` `D` | 移动 |
| `空格` | 开火 |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |
| `Enter` | 开始 / 重新开始 |

## 🚀 运行方式

直接双击 `index.html` 即可在浏览器中游玩，也可以部署到任意静态托管(如 GitHub Pages)。

```bash
# 本地命令行打开
open index.html
```

## 🖥️ 技术说明

- 单个 `index.html` 文件，核心逻辑约 700 行
- 坦克采用网格对齐移动(经典手感)，碰撞检测基于 `56×56` 像素瓦片
- 子弹使用分段移动避免高速穿墙
- 敌人 AI：随机巡逻 + 同行/列视线通畅时自动索敌开火

---

玩法灵感来自经典红白机游戏《Battle City》，代码为独立实现。
